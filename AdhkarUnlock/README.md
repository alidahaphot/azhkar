# أذكار الصباح والمساء عند فتح الهاتف

تطبيق أندرويد (Kotlin، بدون أي مكتبات خارجية). عند كل فتح للهاتف تظهر بطاقة بذكر واحد:
أذكار الصباح من 4 ص إلى 3 م، وأذكار المساء في بقية اليوم. تتبدل الأذكار بالتسلسل مع كل فتح.

## الحصول على ملف APK

### الطريقة 1: Android Studio
1. افتح مجلد المشروع في Android Studio ثم انتظر انتهاء مزامنة Gradle.
2. من القائمة: Build > Build Bundle(s) / APK(s) > Build APK(s).
3. الملف يظهر في: app/build/outputs/apk/debug/app-debug.apk

### الطريقة 2: GitHub Actions (بدون تثبيت شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كما هي (بما فيها المجلد المخفي .github).
2. افتح تبويب Actions، ثم شغّل Build APK (يعمل تلقائيًا مع كل رفع).
3. بعد اكتماله (3 إلى 5 دقائق) نزّل adhkar-apk من قسم Artifacts، وفك الضغط لتحصل على app-debug.apk.

## الإعداد بعد التثبيت (مرة واحدة)
افتح التطبيق ونفّذ الأزرار الثلاثة بالترتيب:
1. إذن العرض فوق التطبيقات (ضروري لظهور البطاقة عند فتح القفل).
2. إذن الإشعارات.
3. استثناء التطبيق من توفير البطارية (مهم في هواتف شاومي وسامسونج وهواوي حتى لا تقتل النظام الخدمة).

بعدها يعمل التطبيق تلقائيًا، ويعود للعمل بعد إعادة تشغيل الهاتف.

## تعديلات سريعة
- أوقات الصباح والمساء: Adhkar.kt (MORNING_START و EVENING_START).
- مدة بقاء البطاقة: DhikrService.kt (AUTO_DISMISS_MS).
- أقل فاصل بين بطاقتين: DhikrService.kt (MIN_INTERVAL_MS، الصفر يعني مع كل فتح).
- إضافة أذكار: أضف عنصر Dhikr جديدًا في القائمتين MORNING و EVENING.
